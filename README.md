# 🚌 Bus Ticket Booking System

A web-based **Bus Ticket Booking System** developed using **Django and Bootstrap**. The system allows users to view available buses, select seats, and book tickets, while administrators can manage buses, seats, and bookings through the Django Admin Panel.

## ✨ Features

* 🚌 View available buses
* 🔍 View bus route, date, time, and ticket price
* 💺 Interactive seat selection
* 🎟️ Book available seats
* 👤 Enter passenger details
* 🔐 Django Admin Panel for managing buses and bookings
* ⚡ Automatic seat creation when a new bus is added
* 📊 Booking report
* 💾 Data stored using SQLite database
* 🎨 Responsive Bootstrap UI
* ✨ Animated and modern interface

## 🛠️ Technologies Used

* Python
* Django
* HTML5
* CSS3
* Bootstrap 5
* SQLite
* Animate.css
